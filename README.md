# Swiggy Restaurants Analysis in bengaluru Location wise
This project analyzes Swiggy restaurant data using SQL to discover meaningful insights about restaurant performance, customer preferences, ratings, pricing, cuisines, and location-based food trends.

The analysis helps identify:

Top-rated restaurants
Most loved dishes
Popular restaurant locations
Customer preferences based on ratings and pricing
Best restaurants to order from in different locations

The project transforms raw restaurant data into actionable business insights using SQL queries and analytical techniques.

Key Insights
Some locations have significantly higher restaurant density.
Restaurants with high ratings usually receive more orders.
Certain dishes consistently receive excellent customer feedback.
Premium restaurants maintain higher average ratings.
Location plays an important role in restaurant popularity.
Restaurants with diverse menus attract more customer engagement.
